# Возврат звонков

Сервис автоматического возврата пропущенных звонков.

## Запуск

```bash
pip install -r requirements.txt
python vozvrat-zvonkov-auto-reply.py
```

Открыть: http://localhost:5000

## Demo автоматического перезвона

Открыть `/demo` и нажать «Сымитировать звонок».

Демо не совершает реальных телефонных вызовов.
